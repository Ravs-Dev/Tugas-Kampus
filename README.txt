PJBL-2 MATEMATIKA
Aplikasi Operasi Himpunan dan Diagram Venn Otomatis

Cara menjalankan:
1. Ekstrak folder PJBL2_Himpunan.
2. Buka file index.html menggunakan Google Chrome / Microsoft Edge.
3. Pilih Dataset 1 atau Dataset 2, atau masukkan data sendiri.
4. Klik "Hitung & Tampilkan Diagram".

Teknologi:
- HTML
- CSS
- JavaScript
- Tidak menggunakan database.

Fitur:
- Gabungan A ∪ B
- Irisan A ∩ B
- Selisih A − B dan B − A
- Komplemen A dan B terhadap U
- Diagram Venn otomatis
- Prinsip Inklusi-Eksklusi
- Dua dataset contoh untuk pengujian
